# C User Input Program

A simple C program that takes the user's **name** and **college name** and displays a welcome message.

## 📌 What I Learned

* Variables and character arrays
* Taking input using `scanf()`
* Printing output using `printf()`
* Using `%s` for strings
* Reading text with spaces

## ▶️ Example

```text
Enter your name: Sarthak
Enter your college name: Zeal College of Engineering

Welcome, Sarthak
You are studying at Zeal College of Engineering
```

## 🛠️ Language

**C**

## 🎯 Purpose

This program is created for **C programming practice** and learning basic input/output.
